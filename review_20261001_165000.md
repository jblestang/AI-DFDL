## 2. Multi-Domain Technical Review

### 2.1 Compiler Architecture & Component Lowering Expertise
- **Problem Statement:** Previously, entity validation, multiple-discriminator checks, and assertion conflict validations ran eagerly during raw XML stream tokenization (`parse_annotation_container`). When an included or unreferenced global component in a large schema contained negative test cases or non-target constructs (such as `e3`, `e4`, `e5` in `discriminator.tdml`'s schema `s1`), the entire schema was aborted prior to compiling the target root element.
- **Architectural Solution:**
  1. Relocated syntax and entity validation out of XML parsing into component IR lowering (`validate_property_entities` and `validate_term_assertions`).
  2. Bounded component lowering and validation strictly to components reachable from the target root element or named group (per DFDL §5.2). Global elements not in the target reachable graph are preserved unlowered without triggering premature compilation rejections.
  3. Added `discriminator_count` tracking in `PropertyStore` and enforced `validate_term_assertions` during component graph lowering.

### 2.2 DFDL Specification Conformance Expertise
- **DFDL §9.5 & §15 (Discriminators across Types and Terms):**
  - **Issue:** `xs:group ref` choice branches and element terms with pattern discriminators (e.g. `testKind="pattern" testPattern="\d;"` or `\p{L}{3},\d{3}`) were erroneously evaluated as XPath expressions via `parse_expr`, generating Pest parsing syntax errors.
  - **Correction:** Implemented dual-mode discriminator evaluation in `evaluate_discriminator`:
    - `TestKind::Pattern`: Lookahead bitstream peeking (without advancing reader state) decoded according to term encoding, combined with regex evaluation using anchored expressions `^(?:<pat>)`.
    - Enabled `unicode-gencat` on `regex` dependency in `crates/dfdl-core/Cargo.toml` to support standard Unicode character category classes (`\p{L}`, `\p{Letter}`).
    - Evaluated element pattern discriminators *before* reading element contents, ensuring speculative choice alternative points of uncertainty resolve before length or delimiter consumption occurs.
- **DFDL §9.5.1 (Point-of-Uncertainty Resolution & Choice Backtracking):**
  - **Issue:** When a choice alternative's discriminator failed, if Point of Uncertainty (PoU) was already set or duplicated, backtracking either terminated abnormally or swallowed commit errors.
  - **Correction:** Aligned choice branch execution: if a discriminator fails before PoU commit, state rollback occurs and subsequent alternatives are attempted. If a discriminator succeeds, `pou_stack` resolves to `true`, committing the choice; subsequent failures raise fatal parse errors without backtracking.
- **DFDL §12.3.2 (Binary Formats with Delimited Length):**
  - **Correction:** Removed invalid rejection prohibiting `lengthKind='delimited'` for packed/bcd formats when terminators or separators are in scope.
- **DFDL §12.1 (Encoding-Specified Text Alignment):**
  - **Correction:** Adjusted mandatory alignment check to standard 8-bit text encoding alignment, resolving artificial rejections for 1-byte aligned schemas.

### 2.3 Embedded Safety & `#![no_std]` Verification
- **Target Platform:** `thumbv7m-none-eabi` (ARM Cortex-M3 bare-metal).
- **Audit:**
  - `unicode-gencat` feature in `regex` compiles purely using static tables in `regex-syntax` and does not link `std`.
  - All lookahead peeking operations in `BitReader` use transactional checkpointing and bounded memory buffers (`try_push`, `Vec::with_capacity`, max 1024 peek bytes).
  - Verified clean compilation with zero warnings: `cargo check -p dfdl-core --target thumbv7m-none-eabi --no-default-features`.

The remaining 109 schema compilation rejections in the official benchmark suite fall into distinct, intended standard error clusters:
1. **Separators with Misaligned Encoding (10 test cases):** Deliberate negative test cases testing that text alignment must match encoding specified alignment.

3. **Choice Branch MinOccurs 0 Rejection (6 test cases):** Official negative tests verifying that `minOccurs="0"` on choice elements triggers schema definition errors.
4. **OccursCountKind Expression Missing occursCount (6 test cases):** Official negative tests for missing required expression bindings.
5. **Multi-Character Decimal/Grouping Separators (9 test cases):** Official negative tests for invalid multi-character decimal and grouping separators.
