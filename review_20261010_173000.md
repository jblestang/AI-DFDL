## 1. Scope and Objective

Modularization of the monolithic `crates/dfdl-schema/src/compiler.rs` (~7,200 lines) into 5 focused submodules:
1. `compiler/schema_doc.rs`: XML Schema document parsing, includes, chameleon namespace resolution, cyclic include tracking, URI/catalog resolution (`parse_schema_document_internal`, `resolve_schema_location`).
2. `compiler/elements.rs`: Element declarations, simple and complex types, facet validations (`validate_simple_type_facets`), enumeration representation bindings (`parse_and_validate_enumeration_rep_attributes`, `RepRangeOrVal`), XSD type name resolution.
3. `compiler/groups.rs`: Model groups (`parse_sequence_node`, `parse_choice_node`, `parse_group_ref_node`, `parse_group_definition`), choice branch validations, hidden group element rules, UPA checks.
4. `compiler/annotations.rs`: DFDL annotations (`parse_annotation_container`, `resolve_ref_formats`, `resolve_escape_scheme_ref`, `parse_define_escape_scheme_element`), assertion/discriminator validations, scoping rules.
5. `compiler/lower.rs`: Lowering of validated XSD AST into compiled IR (`CompiledSchema`, `CompiledElement`, `CompiledSequence`, `CompiledChoice`), default value parsing, implicit alignment computation, DFDL value coercion, Daffodil extension layers.

`compiler.rs` retains the coordinator role:
- Definition of `SchemaCompiler` and `InvalidRestrictionPolicy`.
- Tunables configuration and builder methods.
- Public compilation entry points (`compile_str`, `compile_str_with_root`, `compile_str_with_resolver`, `compile_str_with_resolver_and_root`).
- Submodule declarations and crate-internal symbol re-exports.

## 2. Technical Evaluation by Domain

### A. Compiler Architecture & Code Organization
- **Cohesion and Separation of Concerns:**
  - Before: A single file of 7,200 lines handled everything from XML pull-event parsing to XSD AST construction, type facet checking, DFDL annotation inheritance, and IR generation.
  - After: Each phase of schema compilation is isolated into a dedicated submodule with explicit responsibilities and interfaces.
- **Maintainability:**
  - `compiler.rs` reduced from ~7,200 lines to ~260 lines.
  - Submodules are structured logically around the schema compilation pipeline.

### B. Safety, Memory Footprint & Portability (`no_std` + `alloc`)
