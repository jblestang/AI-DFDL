## 2. Standards Compliance & Architectural Review

### 2.1 W3C XML 1.0 §3.1: Empty-Element Tag Event Symmetry
- **Standard:** W3C Extensible Markup Language (XML) 1.0 (Fifth Edition) §3.1 defines empty-element tags (`<tag/>`) as syntactically equivalent to `<tag></tag>`.
- **Finding:** In `dfdl-xml::reader::XmlReader`, encountering `ElementEnd::Empty` was immediately popping the element context and emitting `XmlEvent::EndElement`. This violated consumer invariants where every `StartElement` event must be preceded or paired symmetrically. In TDML test runners comparing infosets, self-closing tags produced unexpected `EndElement` events without matching `StartElement`.
- **Resolution:** Modified `XmlReader` to emit `XmlEvent::StartElement` upon encountering an empty tag, while staging a synthetic `XmlEvent::EndElement` in a pending events buffer.

### 2.2 TDML Specification §4: Packed Bit Part Decoding
- **Standard:** The TDML specification allows document parts of type `dfdl:documentPart type="bits"`, specifying binary bitstreams as space-separated or contiguous binary strings (`01010101`). Furthermore, `dfdl:bitOrder` can be `mostSignificantBitFirst` or `leastSignificantBitFirst`.
- **Finding:** `crates/dfdl-tests/src/tdml.rs` treated document parts without special bits decoding, failing binary bit tests with bit-level offsets.
- **Resolution:** Implemented `assemble_document_bytes` bit-packing with MSBFirst and LSBFirst RTL bit assembly.

### 2.3 DFDL 1.0 §12.1 & §14: Complex Element Initiators & Terminators
- **Standard:** In DFDL 1.0, both simple and complex elements can have initiators (`dfdl:initiator`) and terminators (`dfdl:terminator`). For a complex element, the initiator precedes the sequence/choice containing its children, and the terminator follows all children.
- **Finding:** `crates/dfdl-core/src/kernel/parser.rs` previously constrained delimiter matching with `if matches!(elem.type_ir, CompiledType::Simple(_))`. This caused complex element wrappers to skip initiator consumption and fail with leftover data.
- **Resolution:** Generalized delimiter parsing so complex elements consume their initiator before processing child components and consume their terminator after completing children.

### 2.4 DFDL 1.0 §12.3: `lengthUnits="characters"` UTF-8 Slicing
- **Standard:** When `dfdl:lengthUnits="characters"` and `dfdl:encoding="UTF-8"`, the length represents the count of Unicode code points / characters, not raw byte counts.
- **Finding:** Fixed-length slicing was using raw byte indexing, truncating multi-byte characters or failing when multi-byte UTF-8 code points were encountered.
- **Resolution:** Added `read_utf8_char_bytes` helper and character-aware length slicing in both binary and text value parsers.

### 2.5 DFDL 1.0 §2.2 & §21: Separation of Parsing and Validation
- **Standard:** DFDL 1.0 §2.2 states that parsing can succeed even when the resulting data violates XML Schema facets (such as `enumeration`, `minInclusive`, etc.), unless validation is enabled. Validation modes (`off`, `limited`, `full`) dictate facet enforcement.
- **Finding:** The parser previously rejected values violating enum facets even with validation disabled, causing false test failures.
- **Resolution:** Introduced `ValidationMode` (`Off`, `Limited`, `Full`), default `Off`, and gated facet checks accordingly.

## 3. Residual Analysis & Next Action Plan

With 422 errors remaining in the cluster:
1. **143 cases of Leftover Data:** Traced to sequence delimiter longest-match ambiguities (e.g. sequence separator `:` vs sequence terminator `::` where separator is a prefix of terminator) and optional trailing element suppression (`separatorSuppressionPolicy="anyEmpty"`).
2. **94 cases of Insufficient Binary Data:** Bit alignment preservation across consecutive unaligned binary reads when `lengthUnits="bits"` transitions across byte boundaries.

All existing and new unit tests pass cleanly (176 tests), clippy passes with zero warnings, and `#![no_std]` + `alloc` compatibility on embedded targets (`thumbv7m-none-eabi`) remains strictly preserved.
