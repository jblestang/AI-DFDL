## 1. Summary of Analysis & Clustering
The "Expected Error Not Raised" test failure use case occurs when the TDML runner executes a test case expecting a Parse, Validation, or Schema Definition Error, but the parser or unparser engine succeeds without raising the required error.

Analysis of the test failures revealed three primary failure clusters by origin:

1. **Cluster 1: Primitive Scalar Integer Range Validation on Parse (DFDL §13.1)**
   - *Origin:* In `crates/dfdl-core/src/kernel/parser.rs` (`parse_text_value`), text integers were cast to primitive scalar types (`xs:byte`, `xs:short`, `xs:int`, `xs:unsignedByte`, `xs:unsignedShort`, `xs:unsignedInt`) via truncation (`as i8`, `as i16`, `as i32`, `as u8`, `as u16`, `as u32`) without bounds validation.
   - *DFDL Standard:* Section 13.1 mandates raising a Parse Error if the parsed scalar value falls outside the value space of the primitive type.
   - *Location & Fix:* Refactored `parse_text_value` in `crates/dfdl-core/src/kernel/parser.rs` to validate parsed integer values against scalar bounds using `i8::try_from`, `i16::try_from`, `i32::try_from`, `u8::try_from`, `u16::try_from`, and `u32::try_from`.

2. **Cluster 2: BCD / Packed Decimal Nibble Error Classification (DFDL §13.7)**
   - *Origin:* In `crates/dfdl-core/src/util.rs` (`decode_packed_decimal`), invalid high and low BCD nibbles returned generic error strings instead of standard-aligned nibble error diagnostics.
   - *DFDL Standard:* Section 13.7 requires identifying high vs low nibble violations when parsing packed decimal binary data.
   - *Location & Fix:* Updated `decode_packed_decimal` in `crates/dfdl-core/src/util.rs` to distinguish between invalid high nibbles and invalid low nibbles.

3. **Cluster 3: SimpleType Restriction Facets & `dfdl:checkConstraints` Evaluation (DFDL §15.4)**
   - *Origin:* In `crates/dfdl-core/src/expr/eval.rs`, `checkConstraints` was previously stubbed to return `true`.
   - *DFDL Standard:* Section 15.4 requires `dfdl:checkConstraints` to evaluate simpleType restriction facets (`maxExclusive`, `maxInclusive`, `minExclusive`, `minInclusive`, `pattern`).
