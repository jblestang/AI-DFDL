## 1. Executive Summary & Profiling Methodology

In accordance with project engineering rules and Karpathy behavioral guidelines, a comprehensive dynamic sampling profile was conducted on the release binary (`dfdl-benchmark`) executing the realistic military tactical data link benchmark (OpenDFDL FakeTDL assets: `test_msg_01.dat` 64-byte radar track and `test_file_01.dat` 192-byte multi-message telemetry).

The target process was profiled using macOS native kernel sampling (`sample`) at 1 kHz over a sustained 6-second window with 300,000 benchmark iterations. The analysis identified four distinct CPU and allocation bottlenecks within the interpreted DFDL kernel.

Following targeted, surgical remediation:
- **Zero compiler warnings** (`cargo check --all-targets` with 0 warnings).
- **100% conformance preserved**: all 281 `dfdl-core` unit tests and the official Apache Daffodil TDML test suite pass with zero regressions.
- **~2× speedup** achieved across the entire interpreted DFDL AST engine (unparse latency reduced by over 50%, roundtrip latency reduced from ~16.5 µs down to 8.37 µs).

## 2. Profile Hotspots & Root Cause Analysis

### Hotspot 1: `InfosetPath` & `PathStep` Allocations (918 samples in baseline)
- **Trace:** `InfosetPath::try_push` (643 samples) + `PathStep::from_segment` (275 samples).
- **Root Cause:** In [`crates/dfdl-core/src/infoset/tree.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/infoset/tree.rs), `InfosetBuilder::current_path(&self)` repeatedly re-traversed the entire element stack from root to leaf on every dynamic expression evaluation, discriminator check, and delimiter resolution. At each stack level, it filtered all parent children, formatted a dynamic string (`alloc::format!("{}[{}]", ...)`), and parsed the segment into a newly allocated `PathStep` and `InfosetPath`.
- **Impact:** In complex nested military telemetry (FakeTDL messages), millions of short-lived string and vector allocations saturated the system allocator (`_xzm_free` / `_malloc_zone_malloc`).

### Hotspot 2: Delimiter Extraction & Active Delimiters Churn (711 samples in baseline)
- **Trace:** `extract_delimiter_tokens` (407 samples) + `write_evaluated_delimiter` (304 samples) in [`crates/dfdl-core/src/kernel/unparser/framing.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/framing.rs).
- **Root Cause:** In [`crates/dfdl-core/src/kernel/unparser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/mod.rs), elements and sequence members unconditionally evaluated delimiter tokens for `props.separator` and `props.terminator`—even when empty strings (`""`) were configured as defaults by `dfdl:format`.
- **Impact:** Each empty delimiter triggered string cloning, expression checking, entity lookahead, and dynamic alternative splitting, only to yield an empty vector.

### Hotspot 3: Dynamic `Vec<&InfosetElement>` Allocations in `find_child_elements` (216 samples in baseline)
- **Trace:** `find_child_elements` in [`crates/dfdl-core/src/kernel/unparser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/mod.rs).
- **Root Cause:** Sibling element matching for occurrences during sequence unparsing called `find_child_elements`, which allocated a new `Vec<&InfosetElement>` on every sequence member.
- **Impact:** For a sequence of 10 elements, 10 separate heap allocations were instantiated and immediately discarded after a single loop iteration.

### Hotspot 4: Binary & Text Calendar Padding and Clones (226 samples in baseline)
- **Trace:** `unparse_binary_calendar` and text calendar formatting in [`crates/dfdl-core/src/kernel/unparser/element.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/element.rs).
- **Root Cause:** Prepending padding zeroes to packed BCD digits used a `while digits.len() < target_digits { digits.insert(0, 0); }` loop, causing $O(N^2)$ memory shifts. Constant calendar properties (`calendarLanguage`, `calendarTimeZone`) were also cloned into owned `String` instances on every scalar unparse.

## 3. Surgical Implementation & Design Decisions

### 3.1 Incremental `current_path` Tracking in `InfosetBuilder`
- In [`crates/dfdl-core/src/infoset/tree.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/infoset/tree.rs), `InfosetBuilder` now incrementally tracks `current_path: InfosetPath`:
  - On `StartElement`: computes the structured `PathStep` directly using `StepTarget::Unprefixed` and index predicates ($O(1)$ stack push).
  - On `EndElement`: pops the step ($O(1)$).
  - On `checkpoint()` / `rollback()`: snapshots and restores `current_path_len`, preserving exact backtracking state without allocations.
  - Added `truncate(len)` to `InfosetPath` in [`crates/dfdl-core/src/types.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/types.rs).

### 3.2 Delimiter Framing Fast Paths
- In [`crates/dfdl-core/src/kernel/unparser/framing.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/framing.rs):
  - `resolve_delimiter_string`, `write_evaluated_delimiter`, and `extract_delimiter_tokens` immediately return for empty raw delimiter inputs (`if raw_delim.is_empty() { return ...; }`).
- In [`crates/dfdl-core/src/kernel/unparser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/mod.rs):
  - Sequences and elements check `!delim.is_empty()` prior to invoking token extraction and pushing to `active_delimiters`.

### 3.3 Zero-Allocation Child Element Slicing
- In [`crates/dfdl-core/src/kernel/unparser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/mod.rs), replaced calls to `find_child_elements` with direct slicing via `find_child_elements_range`:
  ```rust
  let (c_start, c_end) = self.find_child_elements_range(parent_elem, member_id);
  let children_count = c_end.saturating_sub(c_start);
  ```
  Iterates over `parent_elem.children[c_start..c_end]` directly, completely eliminating intermediate vector allocations.

### 3.4 Zero-Copy Calendar Formatting & Stream Index Padding
- In [`crates/dfdl-core/src/kernel/unparser/element.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/element.rs):
  - Replaced vector shifting with direct offset calculation:
    ```rust
    let pad_count = target_digits.saturating_sub(digits.len());
    // Directly reads virtual index: 0 if i < pad_count else digits[i - pad_count]
    ```
  - Borrowed `&str` views for constant `calendarLanguage` and `calendarTimeZone`.
