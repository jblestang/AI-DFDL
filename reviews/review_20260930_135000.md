## 1. Summary of Changes & Architecture Alignment

Pursuant to the DFDL 1.0 Specification (§5.1 simple types, §7.1 annotations & formats, §15 functions) and global workspace compliance guidelines, systemic architectural enhancements were implemented to reduce test failures across Apache Daffodil official TDML suite:

1. **Primitive Built-in XSD Simple Type Resolution (`crates/dfdl-schema/src/compiler.rs`):**
   - Expanded `parse_xsd_type_name` to recognize `xs:decimal`, `xs:dateTime`, `xs:date`, `xs:time`, `xs:nonNegativeInteger`, `xs:positiveInteger`, `xs:nonPositiveInteger`, `xs:negativeInteger`, `xs:anyURI`, `xs:normalizedString`, `xs:token`, `xs:language`, `xs:Name`, and `xs:NCName`.
   - *Impact:* Resolved 353 Schema Compilation Rejection test cases (dropping from 617 to 264 rejections).

2. **XSD Documentation Annotation Handling (`crates/dfdl-schema/src/compiler.rs`):**
   - Updated `parse_annotation_container` to permit `<xs:documentation>` inside `<xs:annotation>` without rejecting standard XML Schema documentation as invalid DFDL annotations.

3. **Global Format Merge Across Includes (`crates/dfdl-schema/src/xsd_ast.rs`):**
   - Updated `XsdSchema::merge` to combine global format default property stores across included/imported schema files (`merge_parent`) and deduplicate defined formats rather than failing on top-level format definitions.

4. **Standard Expression Functions & Math (`crates/dfdl-core/src/expr/eval.rs`):**
   - Implemented `dfdl:checkRangeInclusive($val, $min, $max)` and `dfdl:checkRangeExclusive($val, $min, $max)`.
   - Implemented `xs:hexBinary($val)` string to binary hex conversion.
   - Implemented `fn:round-half-to-even($num, $precision)` with `no_std`-compatible floating point arithmetic.
   - Implemented `fn:trace($val, $label)` returning original value.

5. **Unit Test Suite Expansion (`crates/dfdl-schema/src/lib.rs` & `crates/dfdl-core/src/expr/eval.rs`):**
   - Added unit tests for built-in type resolution (`test_schema_compiler_built_in_types`).
   - Added unit tests for documentation annotation handling (`test_schema_compiler_xs_documentation_handling`).
   - Added unit tests for top-level format merging (`test_schema_compiler_duplicate_format_merging`).
   - Added unit tests for new expression functions (`test_eval_new_functions`).
