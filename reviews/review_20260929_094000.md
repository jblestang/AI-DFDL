## Architectural Root Causes & Standard Requirements

1. **Primitive Binary Read Bounds (§12.3)**:
   - When reading binary scalars in optional elements or choice branch probes, hitting stream EOF should trigger soft EOF / backtracking rather than an unrecoverable hard parse rejection.

2. **Calculated Element Property Scoping (§17.1)**:
   - Elements with `dfdl:inputValueCalc` must be identified at schema compile time across all declaration forms (`<xs:element dfdl:inputValueCalc="...">`, `<dfdl:element inputValueCalc="...">`, `<dfdl:property name="inputValueCalc">`, global element references) so bitstream reads are strictly bypassed.

3. **Explicit Text Length Units (§12.2)**:
   - Explicit length text scalar reading must account for `dfdl:lengthUnits` (`Bits`, `Bytes`, `Characters`) and handle stream EOF gracefully when parsing optional or separator-suppressed sequence fields.

4. **Empty Document Infoset Construction (§14.1)**:
   - Empty input streams with optional root elements must produce an empty infoset or clean validation error without throwing document incomplete panics.
