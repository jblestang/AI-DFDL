## 1. Domain & Specification Conformance (DFDL 1.0 §16 Array & Optional Elements)
- **`OccursCountKind` Policy Support**:
  - `Fixed`: Elements repeat according to `minOccurs` / `maxOccurs`.
  - `Parsed`: Element array parses until stream EOF, failure, or delimiter after `minOccurs`.
  - `Expression`: Dynamic evaluation of `dfdl:occursCount="{...}"` using the Pest expression engine and `ExprContext`.
  - `StopValue`: Reserved policy for designated stop-value terminated array parsing.
- **Sequence-Array Interaction**:
  - `ParserEngine` handles sequence separators (`Infix`, `Prefix`, `Postfix`) transparently between array occurrence element instances.
  - `UnparserEngine` collects all array occurrence elements (`find_child_elements`) and emits delimiters correctly between each array item.
