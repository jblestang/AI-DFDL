## 1. Domain Expertise (Tactical Data Links & C2 Systems)
- **Profile Confinement**: The user requested that the STANAG 5602 (SIMPLE) implementation strictly cover only `tdlType = 3` (Link 16 / STANAG 5516 / TADIL J) and that any frame with another TDL identifier be unconditionally rejected.
- **Simplification**: Rather than maintaining a polymorphic dispatch or a generic fallback (`rawByte`), the payload structure is streamlined directly to `<xs:element name="link16" type="Link16PayloadType"/>`. This reflects dedicated operational gateways that exclusively bridge SIMPLE UDP/IP sessions to Link 16 J-Series networks.
- **Multi-layer Composition**: Clean integration between Layer 1 (STANAG 5602 transport header, 28 bytes) and Layer 2 (Link 16 J3.2 Air Track, J2.2 Identification, J0.0 Round Trip Time / Ack).

## 2. Cybersecurity & Robustness
- **Defense in Depth**:
  - **Facet Bounds**: `TdlType` simpleType defines `minInclusive="3"` and `maxInclusive="3"`, preventing any invalid numerical value at schema validation time.
  - **DFDL Assertion**: `<dfdl:assert test="{ . eq 3 }" message="Unsupported TDL type: only Link 16 (tdlType = 3) is accepted"/>` enforces immediate stream-level rejection on decoding before parsing any payload bytes.
- **Rejection Testing**: Added negative unit tests (`test_stanag5602_simple_reject_non_link16_tdl`) confirming that packets with `tdlType = 0` (Generic), `tdlType = 1` (Link 11A), or `tdlType = 4` (Link 22) fail parsing with a descriptive validation error.

- **Scoped Sibling Resolution**:
