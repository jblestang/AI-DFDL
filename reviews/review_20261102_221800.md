# Code Review: CLI Size Limits & Human-Readable Suffixes in `dfdl-pcap-gen`

**Date / Timestamp:** 2026-11-02T22:18:00+01:00  
**Domains:** CLI Usability, Data Budgets, PCAP Generation, Unit Parsing

---

## 1. Context & User Query
The user observed:
```bash
target/debug/dfdl-pcap-gen --mode exhaustive -o budgeted.pcap -n 5000 --max-payload-size 200 --max-size 1200
```
produced only 4 packets (1056 bytes) and stopped with:
`[i] Info: Stopped generation upon reaching --max-size budget (1056 bytes written, budget: 1200 bytes).`
While the user expected 5000 messages.

---

## 2. Technical Explanation & Physical Limits
- **PCAP File Structure & Minimum Framing Overhead:**
  - Global Header: 24 bytes.
  - Per packet overhead:
    - PCAP Record Header: 16 bytes.
    - Ethernet II MAC Header: 14 bytes.
    - IPv4 Header: 20 bytes.
    - UDP Header: 8 bytes.
    - Total framing overhead per packet = **58 bytes** (without any payload data).
  - With a payload of up to 200 bytes (e.g. average ~200 bytes), each packet occupies $\approx 258$ bytes.
- **Budget Calculation for 1200 bytes:**
  - Available space for packets: $1200 - 24 = 1176$ bytes.
  - Number of packets that fit: $\lfloor 1176 / 258 \rfloor = 4$ packets ($4 \times 258 + 24 = 1056$ bytes).
  - A 5th packet would require $1056 + 258 = 1314$ bytes, exceeding the 1200-byte strict cap.
- **Minimum file size for 5000 packets:**
  - Even with 0 bytes of payload: $24 + 5000 \times 58 = 290{,}024$ bytes ($\approx 283$ KB).
  - With payloads up to 200 bytes: $24 + 5000 \times 258 \approx 1{,}289{,}244$ bytes ($\approx 1.29$ MB).
  - Therefore, fitting 5000 packets into 1200 bytes is physically impossible.

---

## 3. Improvements Implemented
1. **Added Human-Readable Size Suffixes to CLI (`parse_byte_size`):**
   - Added support for `KB` / `K`, `MB` / `M`, `GB` / `G`, and `B` suffixes to `--max-size` and `--max-payload-size`.
   - Examples: `--max-size 1.5MB`, `--max-size 1200KB`, `--max-size 500K`.
2. **Clarified Usage:**
   - If 5000 packets are desired without size truncation: omit `--max-size`.
   - If both `-n 5000` and `--max-size` are set, `--max-size` should be set to at least `1.5MB` (or `1500000`).
