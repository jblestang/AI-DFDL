## Detailed Cluster Analysis

### 1. `Insufficient binary data for primitive scalar` (327 cases)
- **Symptom**: `DFDLError { kind: Parse, message: Static("Insufficient binary data for primitive scalar") }`
- **Mechanism**: In `parse_binary_value`, fixed-width binary reads (`32` bits for `Int`/`Float`, `64` bits for `Long`/`Double`) are attempted regardless of available bitstream bits. When the remaining stream is shorter (e.g. 8 bits or 16 bits in optional array elements or choice branches), `read_binary_bits` errors out.
- **DFDL Standard Alignment**: DFDL §12.3 requires binary scalar parsing to handle stream EOF as soft EOF in backtracking contexts (array occurrences, choice branches, optional elements).

### 2. `Failed to parse text int scalar` (135 cases)
- **Symptom**: `DFDLError { kind: Parse, message: Static("Failed to parse text int scalar") }`
- **Mechanism**: Test cases in the `InputValueCalc_*` family evaluate elements with `dfdl:inputValueCalc`. If property store resolution or element scope lookup fails to tag the element as calculated, `parse_single_element_occurrence` attempts a text stream parse. Because `inputValueCalc` elements have no stream representation, text integer parsing fails on empty string inputs.
- **DFDL Standard Alignment**: DFDL §17.1 specifies that elements with `dfdl:inputValueCalc` MUST NOT consume any bits from the input bitstream and must evaluate exclusively via expression context.

### 3. `Insufficient text data for explicit length scalar` (39 cases)
- **Symptom**: `DFDLError { kind: Parse, message: Static("Insufficient text data for explicit length scalar") }`
- **Mechanism**: When `dfdl:lengthKind="explicit"` is set and `length` evaluates to $N$, `parse_text_value` attempts to read $N$ bytes. If the stream contains fewer than $N$ bytes (e.g., character encoding mismatch or trimmed delimiters), a hard parse error is thrown.
- **DFDL Standard Alignment**: DFDL §12.2 requires explicit length text fields to truncate or return `SoftEof` when parsing optional or variable-occurrence elements.

### 4. `Infoset document incomplete: no root element` (2 cases)
- **Symptom**: `DFDLError { kind: Parse, message: Allocated("Infoset document incomplete: no root element") }`
- **Mechanism**: Thrown by `InfosetBuilder::build` when parsing terminates before any element start event is pushed to `self.doc`.
- **DFDL Standard Alignment**: DFDL §14 requires producing an empty root element or appropriate schema definition error when the root element is optional and absent.
