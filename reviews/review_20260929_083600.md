## Architectural Rationale

Previously, element lookups in `tree.rs::find_element` performed string splitting (`split(':')`) at runtime on every step evaluation to remove XML namespace prefixes (e.g. `ex:num1` -> `num1`). 

### Refactored Implementation

1. **Path Entry Normalization**:
   - `InfosetPath::try_push` ([`crates/dfdl-core/src/types.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/types.rs#L173-L182)) now automatically decomposes and strips QName prefixes (`split(':').next_back()`) as segments are pushed or parsed.
   - Guaranteed Invariant: All segments stored in an `InfosetPath` are pre-decomposed local names.

2. **Zero-Allocation Tree Traversal**:
   - `find_element` ([`crates/dfdl-core/src/infoset/tree.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/infoset/tree.rs#L123-L158)) now compares clean `&str` references directly (`seg == &curr.name.local_name` and `&elem.name.local_name == target_name`), eliminating runtime string splitting and allocation overhead during tree navigation.
