## 1. Domain Expertise (NATO Tactical Communications & STANAG 5602)
- **Native Control Decomposition**:
  - Created a dedicated, modular schema `stanag5602_control.dfdl.xsd` modeling native SIMPLE management and control frames (`tdlType = 0`), matching NATO standard operational practice and Wireshark dissector conventions.
  - Implemented 4 core functional message types:
    1. **Platform / Radio Terminal Status & Keep-Alive (`messageType = 3`)**: terminal state, synchronization quality, frequency-hopping net number, RF power in Watts, crypto key status, 3D position coordinates, BITE error flags.
    2. **Time Synchronization & Round-Trip Timing (`messageType = 2`)**: four-timestamp sequence ($T_1, T_2, T_3, T_4$), computed round-trip delay, and clock offset nanoseconds.
    3. **RF Transmission Event (`messageType = 4`)**: carrier frequency, channel bandwidth, radiated power, modulation, antenna geometry.
    4. **Connection & Message Filter Configuration (`messageType = 5`)**: rule types (geographic AOI, track number, J-series label), action masks, bounding geocage boundaries.
- **Strict Profile Confinement**:
  - `TdlType` restricts accepted identifiers strictly to `0` (Native SIMPLE Control) and `3` (Link 16 / STANAG 5516).
  - Any other value (`1`, `2`, `4..255`) is unconditionally rejected by DFDL assertion and facet bounds.

## 2. Software Architecture & VM Compiler
- **Modular Inclusion**:
  - Main schema `stanag5602_simple.dfdl.xsd` cleanly includes `stanag5602_control.dfdl.xsd` and `link16.dfdl.xsd` without circular or tangled dependencies.
- **Dynamic Choice Dispatch on Siblings**:
  - In `crates/dfdl-vm/src/compiler.rs`, enhanced `lower_choice` to resolve discriminator keys from sibling registers when `choiceDispatchKey` targets a sibling field (e.g., `{ xs:string(tdlType) }` or `{ xs:string(../messageType) }`).
  - Extended AST sibling reference extractor to support single-step paths and function calls (`FnCall`).
  - Complex element definitions are traversed with a `BTreeSet<NodeId>` cycle guard, ensuring complete register pre-allocation for sibling discriminators across sequence nesting.
