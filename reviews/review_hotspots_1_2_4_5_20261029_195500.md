## 1. Executive Summary

Following the profiling analysis in `review_faketdl_profiling_v3_20261029_194500.md`, four targeted optimizations were implemented across the core schema and engine:

1. **Hotspot #1**: Precomputation of [`term_has_representation`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/schema/ir.rs#L1793) at schema compile time into [`CompiledSchema::term_representation`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/schema/ir.rs#L1756) ($O(1)$ zero-alloc lookup instead of dynamic graph recursion with heap `Vec<NodeId>` allocations).
2. **Hotspot #2**: Zero-allocation delimiter stack bookmarking (`.len()` and `.truncate()`) replacing whole-vector cloning of `in_scope_delimiters` and `in_scope_terminators` on checkpoints and peeks.
3. **Hotspot #4**: Bypass of `count_child_occurrences` for scalar elements (`max_occurs == Some(1)`), eliminating repetitive linear scans over infoset sibling nodes.
4. **Hotspot #5**: Lazy `has_subsequent_output` evaluation in sequence unparsing and exact-capacity allocation via `find_child_elements_range`.

All optimizations were achieved with **zero breaking changes to public APIs**, 100% specification conformance, **0 clippy warnings** (with `-D clippy::indexing-slicing`), and all 18 benchmark tests passing.

## 3. Detailed Technical Modifications

### 3.1 Hotspot #1: Precomputed Term Representation Cache
- **Files Modified**:
  - [`crates/dfdl-core/src/schema/ir.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/schema/ir.rs)
  - [`crates/dfdl-core/src/schema/builder.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/schema/builder.rs)
- **Changes**:
  - Added `pub term_representation: Vec<bool>` to `CompiledSchema`.
  - Added `CompiledSchema::precompute_term_representations(&mut self)` to compute physical representations once during schema building.
  - Rewrote `CompiledSchema::term_has_representation` to use an $O(1)$ lookup with fallback:
    ```rust
    #[inline]
    #[must_use]
    pub fn term_has_representation(&self, term_id: NodeId) -> bool {
        if let Some(&has_rep) = self.term_representation.get(term_id.0 as usize) {
            has_rep
        } else {
            let mut visited = alloc::vec::Vec::new();
            self.term_has_representation_impl(term_id, &mut visited)
        }
    }
    ```

### 3.2 Hotspot #2: Delimiter Checkpoint Bookmarking & Non-Cloning Peek
- **Files Modified**:
  - [`crates/dfdl-core/src/kernel/parser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/parser/mod.rs)
  - [`crates/dfdl-core/src/kernel/parser/element.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/parser/element.rs)
  - [`crates/dfdl-core/src/kernel/parser/delimiters.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/parser/delimiters.rs)
- **Changes**:
  - Replaced `self.in_scope_delimiters.clone()` and `self.in_scope_terminators.clone()` on choice and element occurrence checkpoints with `self.in_scope_delimiters.len()`.
  - Replaced whole-vector restoration with `self.in_scope_delimiters.truncate(delims_cp)` and `self.in_scope_terminators.truncate(terms_cp)`.
  - Rewrote `is_in_scope_terminator_longer` and `peek_any_in_scope_delimiter` in `delimiters.rs` to iterate by reverse index with early return on empty stack, eliminating vector duplication.

### 3.3 Hotspot #4: Bypass Occurrence Counting on Scalar Elements
- **Files Modified**:
  - [`crates/dfdl-core/src/kernel/parser/element.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/parser/element.rs)
- **Changes**:
  - In `parse_element_with_separators` and `parse_single_element_occurrence_inner`, if `elem.max_occurs == Some(1)`, immediately set `current_occurs_index = 1` without traversing the parent element's children.
  - For array elements (`max_occurs > 1`), queried `count_child_occurrences` once before the loop and tracked occurrences via local counter.

### 3.4 Hotspot #5: Lazy Unparser Subsequent Output & Range Scanning
- **Files Modified**:
  - [`crates/dfdl-core/src/kernel/unparser/mod.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/kernel/unparser/mod.rs)
- **Changes**:
  - Evaluated `has_subsequent_output` lazily only when separators are configured AND the separator suppression policy requires trailing empty detection (`TrailingEmpty` or `TrailingEmptyStrict`).
  - Added `find_child_elements_range(&mut self, parent, term_id) -> (usize, usize)` to identify child spans without allocations.
  - Replaced dynamic buffer reallocation in `find_child_elements` with exact-sized pre-allocation `Vec::with_capacity(count)`.
