## Remarks (dev / DFDL spec)
1. `pattern.rs`: look-ahead must be the last consuming construct of its alternative; mid-pattern
   look-ahead reports an approximate consumed length. Negative look-ahead / look-behind rejected.
2. `pattern.rs`: patterns are byte-oriented on decoded `&str`; `\xFF`-style hexBinary
   lengthPatterns (`hexBinaryLengthKindPattern01`) still need a bytes regex (`regex::bytes`).
3. xs:pattern facets (`ir.rs`) still use plain `regex` (XSD regex has no look-around: OK).
4. Rounding: mode/increment honoured only when `textNumberRounding="explicit"` (spec); pattern
   mode uses ICU default half-even. Pattern-implied increments only on non-exponent patterns.
5. Rounding: scientific pattern with `max_int > 1` and carry past width renormalises to one digit.
6. `E+000` exponent pattern (forced `+` sign) is still not emitted for positive exponents.
7. Safety: all slicing in `rounding.rs` is checked; exponent expansion capped at |1000|;
   increment arithmetic capped at 36 digits (falls back to digit rounding).
