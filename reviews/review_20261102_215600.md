# Revue Technique : Reclassification Syntaxe/Sémantique et Anomalie de Valeur Constante

- **Date** : 02 Novembre 2026 - 21:56:00
- **Composant** : `crates/dfdl-payload-generator` (`syntax.rs`, `semantic.rs`, `schema_walk.rs`, `generator.rs`, `main.rs`, `README.md`, tests)
- **Objectif** : Reclassification formelle de `WrongDispatchKey` en anomalie syntaxique, ajout de `WrongConstantValue` comme anomalie sémantique, introspection de schéma pour champs constants, et zéro warning clippy/compilateur.

---

## 1. Contexte et Justification Formelle

### A. Pourquoi `WrongDispatchKey` est une anomalie syntaxique
Dans la spécification DFDL (Data Format Description Language) et dans la théorie des grammaires formelles :
- **Anomalie syntaxique** : Empêche la sélection d'une production grammaticale valide ou corrompt le cadrage/décodage de la séquence de symboles.
- Dans un élément `<xs:choice dfdl:choiceDispatchKey="...">`, la clé de dispatch (`choiceDispatchKey`) pilote directement la sélection de branche de la grammaire.
- Lorsqu'une valeur inconnue ou inexistante dans les branches de choix (`choiceBranchKey`) est rencontrée, le parser ne peut pas dériver l'arbre syntaxique (échec de résolution de branche à l'analyse syntaxique). Ce n'est pas une valeur valide qui viole une contrainte métier, c'est un échec d'aiguillage structurel de la grammaire.
- En conséquence, `WrongDispatchKey` a été transféré de `SemanticAnomaly` vers `SyntaxAnomaly::WrongDispatchKey { discriminator_name, invalid_key }`.

### B. Pourquoi `WrongConstantValue` est une anomalie sémantique
- Une valeur constante (telle qu'un `dfdl:magicNumber`, un champ avec `default`, une énumération à valeur unique, ou un champ scalaire avec `minInclusive == maxInclusive`) possède une représentation binaire syntaxiquement valide et décodable.
- Le flux d'octets respecte la grammaire et produit un nœud d'infoset valide, mais la valeur viole le contrat sémantique du protocole ou de la spécification de format.
- `WrongConstantValue { target_name, expected_value, invalid_value }` a donc été créé dans `SemanticAnomaly` pour cibler ces éléments.

## 2. Modifications Réalisées

1. **`crates/dfdl-payload-generator/src/syntax.rs`** :
   - Ajout de la variante `SyntaxAnomaly::WrongDispatchKey { discriminator_name: String, invalid_key: DfdlValue }`.
   - Ajustement du derive vers `#[derive(Debug, Clone, PartialEq)]` car `DfdlValue` comprend des types à virgule flottante ne satisfaisant pas `Eq`.
   - Remplacement de `.max(1).min(1024)` par `.clamp(1, 1024)`.

2. **`crates/dfdl-payload-generator/src/semantic.rs`** :
   - Suppression de `WrongDispatchKey`.
   - Ajout de `SemanticAnomaly::WrongConstantValue { target_name: String, expected_value: DfdlValue, invalid_value: DfdlValue }`.
   - Fonction d'altération générique `mutate_element_value` exportée publiquement pour réutilisation dans l'injection d'anomalies syntaxiques d'infoset.

3. **`crates/dfdl-payload-generator/src/schema_walk.rs`** :
   - Ajout du champ `pub default_value: Option<DfdlValue>` dans `ElementFieldInfo`.
   - Implémentation de `SchemaAnalysis::find_constant_fields(&self) -> Vec<(ElementFieldInfo, DfdlValue)>` qui introspecte :
     1. Les éléments avec `default_value` explicite.
     2. Les éléments avec énumération unique (`enumerations.len() == 1`).
     3. Les scalaires avec facettes d'égalité (`min_inclusive == max_inclusive`).
     4. Les champs de protocole identifiés par convention (`version`, `magic`, `sync`, `const`, `protocol`).
   - Correction clippy : utilisation de `.rfind()` au lieu de `.filter().next_back()`.

4. **`crates/dfdl-payload-generator/src/generator.rs`** :
   - Support de `SyntaxAnomaly::WrongDispatchKey` via modification d'infoset et ré-unparsing dans `generate_syntax_anomaly`.
   - Intégration de `SyntaxAnomaly::WrongDispatchKey` dans la section 8 (Syntactic anomalies) de `generate_exhaustive_suite`.
   - Intégration de `SemanticAnomaly::WrongConstantValue` dans la section 11 (Semantic anomalies) de `generate_exhaustive_suite`.
   - Nettoyage des motifs clippy (`is_some_and`, `is_none_or`, struct update syntax).

5. **`crates/dfdl-payload-generator/src/main.rs` & `README.md`** :
   - Documentation complète de la distinction syntaxique vs sémantique.
   - Support des nouvelles options dans l'aide et les rapports d'exécution.
