## 1. Domain & DFDL 1.0 Specification Conformance (OGF GFD-R-P.240 Section 14)
- **Separator Positions**:
  - `Infix`: Separators occur strictly between elements (e.g., `A,B,C`).
  - `Prefix`: Separators occur before every element (e.g., `,A,B,C`).
  - `Postfix`: Separators occur after every element (e.g., `A,B,C,`).
- **Separator Suppression Policies**:
  - Supported `Never`, `TrailingEmpty`, `TrailingEmptyStrict`, and `AnyEmpty` configurations in `ResolvedProperties`.
- **Delimiter Parsing/Unparsing**:
  - Exact literal string matching in `ParserEngine::match_literal_delimiter`.
  - Exact byte writing in `UnparserEngine::write_literal_delimiter`.
  - Delimited text length scanning in `ParserEngine::parse_text_value`.
