## 2. Root Cause Analysis & Technical Solutions

### A. Arbitrary-Precision Binary Integer & Decimal Decoding (`binary.rs`)

#### Root Cause
Under DFDL 1.0 §5.1 and §13.7.1, `xs:decimal`, `xs:integer`, `xs:nonNegativeInteger`, and related derived integer types map to `DfdlSimpleType::Decimal`. While primitive fixed-width integers (`xs:int`, `xs:long`, etc.) have bounded bit widths ($\le 64$), `xs:decimal` and `xs:integer` have arbitrary length when `dfdl:representation="binary"` and `dfdl:lengthKind="explicit"`.

Previously, `ParserEngine::parse_binary_value` routed `DfdlSimpleType::Decimal` through `self.read_binary_bits(bits)`, which internally capped reads at `bits.min(64)`. For elements with length > 8 bytes (such as 12, 16, 32, or 120 bytes), the bit reader consumed only the first 64 bits and left 96–896 bits unread in the stream, triggering:
```text
Parse Error: Left over data remaining after root element parse. Consumed 64 bit(s).
```

#### Implemented Solution
1. **Multi-Precision Decimal Base-10 Formatter (`Self::bytes_to_decimal_string`):**
   - Implemented an allocation-efficient, `#![no_std]` + `alloc` compliant multi-precision division algorithm using 32-bit limbs and radix-$10^9$ reduction.
   - Operates in $O(N^2 / \text{limb\_size})$ time, completing even 120-byte integers in sub-microsecond time.
2. **Two's Complement & Byte Order Normalization:**
   - Supports arbitrary-width two's complement signed integer decoding: checks the most significant bit (handling sub-byte leading bits when `bits % 8 != 0`), inverts all bits, and performs ripple-carry increment (+1) to extract the magnitude.
   - Accurately respects `dfdl:byteOrder` (`BigEndian` vs `LittleEndian`).
3. **Virtual Decimal Point Formatting (`dfdl:binaryDecimalVirtualPoint`):**
   - DFDL 1.0 §13.7.1.3 defines that positive scale inserts a virtual decimal point $N$ places from the right (with leading zero padding when necessary), while negative scale appends $-N$ trailing zeros to the integer. Both directions are now strictly formatted via `Self::format_virtual_decimal_str`.
