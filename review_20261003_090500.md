## Remarks
- Safety: the bound check fires only when more data remains (after the EOF break); matches Daffodil's "limit exceeded" semantics for unbounded arrays. Default is no limit (no behaviour change).
- Dev: OVC evaluation uses a fresh 100k work budget per lookup, so cyclic OVC chains are bounded but not shared with the caller budget.
- Dev: `valueLengthAndOccurs1`, `valueLengthPair1-3` changed from "bytes mismatch" to "unparse failed" (still failing before and after); worth a look as the OVC fallback now exposes a different error.
- Dev (open): `bitOrderOVC1` needs sub-byte text encodings in the unparser (5-bit packed LSBF, octal LSBF), LSBF bit packing across elements and RTL byte order. `encoding.rs` has no 5-BIT-PACKED table. Same root cause fails `packed5Bit_unparse*`, `octalLSBF_unparse*`, `packed6BitASCII_unparse*`. Estimated as a separate feature.
