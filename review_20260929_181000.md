## 2. Implemented Features & Spec Alignment

### A. Pre-defined DFDL & XPath Functions (`eval_fn_call`)
1. **`dfdl:checkConstraints($elem)`** (DFDL §23.5): Evaluates XSD facet constraints against an element value; returns boolean `true` when valid.
2. **Type Constructors & Casting** (XPath 2.0 §5):
   - `xs:double($arg)` / `double($arg)`
   - `xs:int($arg)` / `int($arg)`
   - `xs:float($arg)` / `float($arg)`
   - `xs:string($arg)` / `string($arg)`
   - `xs:boolean($arg)` / `boolean($arg)`
3. **`fn:compare($s1, $s2)`** (XPath 2.0 §7.4.1): Returns `-1`, `0`, or `1` based on codepoint comparison.
4. **`fn:true()` / `fn:false()`** (XPath 2.0 §9.3): Zero-arg boolean functions.
5. **Stream Position & Inspection Functions** (DFDL §23.1):
   - `dfdl:lookAhead(offset, bitLength)`
   - `dfdl:currentPosition()`
   - `dfdl:occursIndex()`
   - `fn:count($arg)`

### B. Pre-defined Standard DFDL Variables (`lookup_variable`) (DFDL §7.4)
- `$dfdl:encoding` -> `"UTF-8"`
- `$dfdl:byteOrder` -> `"bigEndian"`
- `$dfdl:binaryFloatRep` -> `"ieee"`
- `$dfdl:outputNewLine` -> `"\n"`
