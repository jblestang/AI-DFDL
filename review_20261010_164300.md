# Revue Technique — Élimination du parsing manuel de chaînes dans `eval.rs`
**Date :** 10 Octobre 2026 — 16:43:00  
**Auteur :** Antigravity (Paire-programmeur & Expert DFDL / Rust)  
**Objet :** Éradication complète des découpages manuels de chaînes de chemins XPath (`split(':')`, `split('[')`, `split_last()`, boucles `for seg in segments`) dans [`eval.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/expr/eval.rs).

## 1. Contexte et Problématique

L'utilisateur a relevé dans [`crates/dfdl-core/src/expr/eval.rs:353`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/expr/eval.rs#L353) (fonction `fn count`) la persistance de code de manipulation manuelle de chaînes de caractères pour les chemins XPath :
```rust
let segs = path.segments();
if let Some((last_seg, parent_segs)) = segs.split_last() {
    let clean_last = last_seg.split(':').next_back().unwrap_or(last_seg);
    let clean_target = clean_last.split('[').next().unwrap_or(clean_last);
    ...
```

Un audit approfondi de `eval.rs` a révélé que ce pattern fragile et redondant était reproduit à plusieurs endroits :
1. **`count` (l. 353-380)** : découpage manuel pour extraire le parent et le nom local de la cible.
2. **`valueLength` / `contentLength` (l. 394-470)** : normalisation manuelle via boucle sur les segments et stripping de préfixes.
3. **Synthetic element creation pour OVC (l. 518-528)** : stripping manuel de préfixe.
4. **`checkConstraints` (l. 540-575)** : normalisation de chemin réimplémentée manuellement.
5. **`eval_ovc_for_path` (l. 880-895)** : extraction manuelle du nom de l'élément cible.
6. **`normalize_infoset_path` (l. 930-1005)** : inspection de segment racine et extraction de cible avec `split(':')`.
7. **`resolve_path` (l. 1099-1170)** : extraction du nom pour le formatage de messages d'erreur et notation Clark.
8. **Term lookup & self-reference checks (l. 2465-2500)** : extraction manuelle de nom local.

### 2.2 Remplacement dans [`eval.rs`](file:///Users/jean-baptiste/AI-DFDL/crates/dfdl-core/src/expr/eval.rs)
- **`count`** :
  ```rust
  if let Some(last_step) = path.last_step() {
      let clean_target = last_step.local_name();
      let norm_parent = path
          .parent_path()
          .map(|p| p.normalized_against(ctx.current_path))
          .unwrap_or_else(|| ctx.current_path.clone());
      ...
  ```
- **`valueLength` / `contentLength`** :
  ```rust
  let norm = path.normalized_against(ctx.current_path);
  let norm_name = norm.last_step().map(|s| s.raw_target()).unwrap_or("");
  ```
- **`checkConstraints`** :
  ```rust
  let norm = if let Some(ExprAst::Path(path)) = args.first() {
      path.normalized_against(ctx.current_path)
  } else {
      ctx.current_path.clone()
  };
  ```
- **`normalize_infoset_path`** & **`resolve_path`** :
  Utilisation systématique de `norm.last_step().map(|s| s.local_name())` et `last_step.raw_target()`.
