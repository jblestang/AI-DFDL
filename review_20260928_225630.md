## 2. Key Technical Implementations

### A. DFDL Built-in Function Extensions (`crates/dfdl-core/src/expr/eval.rs`)
- **`dfdl:valueLength()` & `dfdl:contentLength()`**: Evaluates simple element length in `bytes` or `bits`.
- **XPath String Built-ins**:
  - `fn:substring($str, $start, $len?)`: 1-based XPath indexing with bounds checking.
  - `fn:contains()`, `fn:starts-with()`, `fn:ends-with()`: String match primitives.
  - `fn:upper-case()`, `fn:lower-case()`: Standard case conversions.
  - `fn:matches($str, $pattern)`: Basic substring/regex pattern matching.
- **XPath Numeric Built-ins**:
  - `fn:abs()`, `fn:ceiling()`, `fn:floor()`, `fn:round()`: Numeric rounding and absolute value functions with saturating arithmetic.

### B. Calendar & Packed Decimal Codecs (`crates/dfdl-core/src/util.rs` & `infoset/value.rs`)
- **Calendar Types**: Added `DfdlSimpleType::DateTime`, `Date`, `Time`, and `Decimal` variants.
- **IBM Comp-3 Packed Decimals**: Implemented `decode_packed_decimal` and `encode_packed_decimal` for BCD binary-coded decimal representations (§13.7) supporting positive (`0x0C`/`0x0F`) and negative (`0x0D`) sign nibbles.

### C. XSD Group & Multi-File Import Resolution (`crates/dfdl-schema/src/compiler.rs` & `xsd_ast.rs`)
- **Named Groups**: Support for `<xs:group name="...">` definitions and `<xs:group ref="...">` inline references.
- **Multi-File Includes & Imports**: Added `SchemaCompiler::compile_str_with_resolver` to resolve `<xs:include schemaLocation="...">` and `<xs:import>` files cleanly with recursion loop protection.

### D. DFDL Variable Definitions & Scoping (`dfdl:defineVariable` & `dfdl:setVariable`) (§7)
- **`VariableMap`**: Added runtime `VariableMap` in `dfdl-core::expr::variables` managing variable declarations (`DfdlVariable`) and active values.
- **`dfdl:defineVariable`**: Schema compilation support for top-level global variable declarations (`<dfdl:defineVariable name="..." type="..." defaultValue="...">`).
- **`dfdl:setVariable`**: Runtime variable assignment support for `<dfdl:setVariable ref="..." value="...">` annotations evaluated prior to term parsing/unparsing.
- **Variable Expression Resolution**: `$varName` expressions look up active values in `VariableMap` with fallback to schema default values.

- `test_packed_decimal_codecs_roundtrip`:
