## 1. Domain Expertise Analysis

### 1.1 DFDL Standard & Schema Architecture Expertise
- **`dfdl:defineFormat` Top-Level and Container Scoping:**
  - *Standard Requirement (DFDL 1.0 §7.1):* `dfdl:defineFormat` provides reusable named collections of format properties. When placed inside `<xs:annotation><xs:appinfo>` or directly at `<xs:schema>` level, its inner `<dfdl:format>` attributes belong strictly to the named format and MUST NOT leak into `schema.global_format`.
  - *Root Cause Discovered:* In `crates/dfdl-schema/src/compiler.rs`, top-level `defineFormat` tags were not dispatched in the outer schema loop, causing their inner `<dfdl:format>` children to be parsed by the fallback `format` handler directly into `schema.global_format`. This corrupted every schema element with properties of the last parsed `defineFormat` (e.g., `prefixedTxtChar` setting `prefixLengthType="ex:threeCharTextInt"` and `lengthUnits="characters"` on all elements).
  - *Fix Applied:* Implemented dedicated `XmlEvent::StartElement` handling for `defineFormat` in both the top-level loop and `parse_annotation_container`, consuming child elements (`format` and `property`) up to matching `EndElement` and saving them into `schema.defined_formats`.

- **Format Reference Cycle Detection:**
  - *Standard Requirement (DFDL 1.0 §7.1):* Circular `ref` chains between defined formats (e.g., `fmtA -> fmtB -> fmtA`) must be safely handled without unbounded recursion or stack exhaustion.
  - *Fix Applied:* Refactored `resolve_ref_formats` into `resolve_ref_formats_bounded` passing `visited_refs: &mut Vec<String>` across all recursive calls, preventing runaway recursion and stack overflow.

### 1.2 Binary & Signal Data Processing Expertise
- **Prefix Length Evaluation:**
  - Supported prefixed length reading for 8, 16, 24, 32, and 64 bits across BigEndian and LittleEndian representations, correctly interpreting 24-bit integers and custom simple types.
  - Addressed multi-token descriptors (`name:rep:len:units`) and avoided panicking slice indexing via Clippy-compliant `.get()` and `.copied()`.

- **Binary Decimal Virtual Point & Calendar Representations:**
  - Implemented `binary_decimal_virtual_point` scaling on binary decimal representations, correctly shifting values into fractional decimal notation (e.g. `12345` with virtual point `2` becomes `123.45`).
  - Implemented `parse_calendar_from_digits` for `packed`, `bcd`, and `ibm4690Packed` calendar representations.

### 1.3 Embedded Systems & Safety Expertise (`#![no_std]` + `alloc`)
- **Memory Safety & Invariants:**
  - Removed temporary debug logging to prevent unauthorized `std` dependencies in `#![no_std]` core modules.
  - Ensured every arithmetic operation uses saturating/checked arithmetic (`saturating_add`, `saturating_sub`).
  - Verified compilation for embedded target `thumbv7m-none-eabi`.
